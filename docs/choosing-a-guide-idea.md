# Carrying a guide idea into the planner

Each practical-guide idea has a stable catalogue ID and a Use this idea in my plan link. The link carries only an allowlisted pillar, idea ID and existing practical preference. It does not put the action text or any visitor-written draft in the URL.

The planner resolves the idea for the explicit pillar only. A valid choice supplies the initial editable action, ahead of the broader guided preference. Unknown, repeated, wrong-pillar and malformed choices fall back to the existing preference/general starter; an invalid or missing pillar does not seed a selected idea. The source link points back to the practical ideas section.

The origin cue is shown only for the original pillar and exact starter wording, before a restore/import revision. Changing the action away from the exact starter hides it; restoring or importing hides it even if the text happens to match. This avoids attributing a restored personal plan to a catalogue source. The normal evidence panel and scope wording remain available after editing.

Native links start a fresh planner document, work without JavaScript and avoid carrying an old in-memory editor through a changed starter URL. Existing saved copies are not read, restored, saved or upgraded by this navigation. Starting a dated week and saving remain explicit choices. No selected-idea ID or provenance is added to storage, backups, text exports or calendars.

Idea text remains in the reviewed learning-guide catalogue, now paired with stable IDs. There is no duplicate medical copy, new claim, review date or institutional endorsement. Existing NHS/WHO/Harvard/CDC references remain intact. Search indexes the same idea text; print handouts retain each idea and hide the interactive links.

Unit and hosted browser coverage verify all catalogue ideas and links, strict lookup/fallbacks, guided-preference precedence, editable/save/restore behavior, server-rendered no-JavaScript navigation, public canonical URLs, private-record isolation, and keyboard layouts at 320/1440px.
