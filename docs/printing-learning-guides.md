It never claims a file was saved. Failure leaves the guide readable and suggests the browser's own Print command. With JavaScript disabled the button is hidden, while browser printing still uses the server-rendered article and print stylesheet.

The print layout uses the same article, not a separately maintained shortened copy. It retains audience scope, title, publisher/source-check date, takeaways, all guidance and practical ideas, numbered citations, source publisher/type/support/scope, and qualified urgent help. The printed source list includes full readable URLs. A print-only header gives the fixed public article URL without preview host, query preference or hash, and repeats the general educational scope.

Navigation, interactive planner/Explorer shortcuts and printing controls are hidden on paper. The movement quick-navigation box is hidden while the actual age-appropriate and adapted-movement sections remain. The column layout becomes one column with black text, wrapping source URLs and headings kept with following content. Source entries avoid page splits where they fit. The existing screen layout and canonical metadata remain unchanged.

This adds no clinical claims, review dates, source endorsements, PDF-generation service or dependency. Existing NHS, WHO, Harvard and CDC context is printed from the same catalogue. It does not read or save personal plans or add measurement events. Guide routes remain outside optional measurement.

Hosted browser coverage verifies all four full print views against catalogue sections and source URLs, real A4 PDFs, retained local urgent contacts and movement adaptation guidance, keyboard printing at 320/1440px, failure handling, personal-record/request isolation and browser printing without JavaScript.
