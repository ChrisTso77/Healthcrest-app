# Debugging loop breaker

- First failure: inspect exact error, state a specific hypothesis, make a targeted
  correction and rerun focused verification.
- Second failed attempt at the same underlying issue: stop repeating that approach.
  Record observed facts separately from assumptions; list at most three causes and
  run the smallest experiment distinguishing them before changing approach.
- Missing supported security tooling: record the failed resource/capability and
  keep L01 blocked; do not rename static inspection as a supported scan.
- CMS/network/storage failures: preserve fallback/current drafts and safety guards;
  do not disable production or overwrite real data to diagnose local behavior.
- Backup failure: preserve prior archives and private logs; no invented restoration
  evidence or recreated originals. Reuse synthetic corruption/path tests first.
- Performance failure: retain the initial measurement and unchanged budgets;
  passing a rerun alone does not explain the cause.
- External/permission blockers: identify the exact needed condition; do not repeat
  unchanged requests or bypass controls. Continue independent authorised work.
