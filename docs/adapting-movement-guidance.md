# Adapting movement guidance

The movement guide now has prominent links to its older-adult and seated-movement sections. The access/space guided starting point links directly to them while preserving idea=access through to the existing editable planner.

Sources checked 28 October 2026:
- https://www.nhs.uk/live-well/exercise/physical-activity-guidelines-older-adults/
- https://www.nhs.uk/live-well/exercise/sitting-exercises/

The 65+ section includes daily light activity, strength/balance/flexibility, appropriate weekly activity guidance and the qualification that vigorous activity is for those already active. The seated section explains the NHS routine's stable-chair assumptions and suitability checks. It links to the full demonstrations without prescribing sets/repetitions or assuming all seating needs are the same.

No age/disability question, new query preference, inferred assessment, stored profile, exercise-dose generator or measurement event is added. The current access starter remains general and editable. Existing 19–64 guidance stays clearly scoped; the additional material does not change Explorer sliders or imply they implement older-adult targets.

The existing catalogue tests validate the added source references, section IDs, search text and metadata. Browser checks cover source/context links, safe planner continuity without saving, search discovery, keyboard layouts and operation without JavaScript.
